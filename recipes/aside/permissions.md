# Aside 권한 설정

## writableRoots 추가

1. **경로 추가 위치**
   - Aside 설정의 writableRoots에서 다음 경로를 추가한다:
   - `~/rooms` - 룸 저장 경로
   - `~/personal` - 작업 위치

2. **설정 방법**
   - 설정 화면/파일에서 `writableRoots` 항목을 찾아 위 경로들을 추가한다.

## Aside 스킬 관리

1. **초기 설정**
   - `./setup --host aside`를 실행하면 스킬이 복사된다.
   - 스킬은 동기화되지 않으므로 변경 후 다시 적용하려면 `./setup --host aside`를 다시 실행해야 한다.

## 실험 가드레일

1. **안전성 제약**
   - 모든 파일 접근은 writableRoots에 제한된다.
   - 시스템 디렉토리에 대한 접근은 불가능하다.
   - 권한 없는 경로 접근 시 명시적 승인이 필요하다.

2. **변경 사항 적용**
   - 스킬 설정을 변경하면 `./setup --host aside`를 다시 실행하여 변경사항을 적용한다.
